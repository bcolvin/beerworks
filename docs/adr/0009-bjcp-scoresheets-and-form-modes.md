# 0009. Unified BJCP Beer Scoresheets, Discipline Selector, and Inline Reference Sheets

We decided to model user-authored BJCP evaluations (**Scoresheets**, presented in the **Reviews** UI) in a unified Room table (`ScoresheetEntity` in `scoresheets`) with a single unified BJCP Beer scoresheet editor and an explicit discipline switcher for future Mead and Cider sheets:

1. **Single Unified BJCP Beer Scoresheet (No Short-Form vs. Long-Form Split)**: Rather than maintaining separate Short-Form and Long-Form modes, preferences, or tables, every Beer Scoresheet uses one unified structure combining integer 50-point section sliders (`Aroma` 0–12, `Appearance` 0–3, `Flavor` 0–20, `Mouthfeel` 0–5, `Overall Impression` 0–10), per-section multi-state tap-cycle descriptor chips (`ScoresheetDescriptor`), optional per-section narrative notes, `Bottle Inspection`, 0–10 impression sliders (`Stylistic Accuracy`, `Technical Merit`, `Intangibles`), and 4-state canonical `OffFlavor` fault chips (`Unset` → `Low` → `Med` → `High` → `Unset`).
2. **Discipline Modeling (`ScoresheetDiscipline`)**: `ScoresheetFormType` was replaced by `ScoresheetDiscipline` (`BJCP_BEER`, `BJCP_MEAD`, `BJCP_CIDER`) with no separate short-form vs. long-form modes. The `formType` column in `scoresheets` stores `discipline.name`, and `ScoresheetDiscipline.fromStorageValue()` resolves `BJCP_BEER`, `BJCP_MEAD`, or `BJCP_CIDER` (defaulting null/unknown values to `BJCP_BEER`). New sheets expose an in-editor `SingleChoiceSegmentedButtonRow` (`Beer` | `Mead` | `Cider`), while `ReviewsScreen` filters evaluations via multi-select discipline toggle `FilterChip`s.
3. **Discipline-Scoped Style Linking**: Style linking on a Scoresheet is scoped to the active `ScoresheetDiscipline`'s guideline (`BJCP_2021` for Beer, `BJCP_MEAD` for Mead, `BJCP_CIDER` for Cider) via a typable searchable dropdown with custom text fallback, backed by `BeerStyleRepository.getStyles(guidelineType)`.
4. **In-Place Reference Quick-Peeks**: To keep unsaved evaluation state intact during judging, tapping the style book icon, any section's `(i)` info icon, the scoring-tier `(i)` guide icon, or long-pressing an Off-Flavor chip opens a single-back `ModalBottomSheet` (`skipPartiallyExpanded = true`) with the linked `BeerStyle` stats/section text, BJCP scoring guide, or `OffFlavor` thresholds and origins, rather than navigating away.
