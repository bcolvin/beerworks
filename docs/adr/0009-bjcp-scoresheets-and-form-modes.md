# 0009. Unified BJCP Beer Scoresheets, Per-Section Descriptor Chips, and Inline Reference Sheets

We decided to model user-authored BJCP Beer evaluations (**Scoresheets**, presented in the **Reviews** UI) in a unified Room table (`ScoresheetEntity` in `scoresheets`) with a single streamlined BJCP Beer scoresheet editor:

1. **Single Unified BJCP Beer Scoresheet**: Rather than maintaining separate Short-Form and Long-Form screens or tables, every Scoresheet uses one unified structure combining integer 50-point section sliders (`Aroma` 0–12, `Appearance` 0–3, `Flavor` 0–20, `Mouthfeel` 0–5, `Overall Impression` 0–10), per-section multi-state tap-cycle descriptor chips (`ScoresheetDescriptor`), optional per-section narrative notes, `Bottle Inspection`, 0–10 impression sliders (`Stylistic Accuracy`, `Technical Merit`, `Intangibles`), and 4-state canonical `OffFlavor` fault chips (`Unset` → `Low` → `Med` → `High` → `Unset`). The `formType` column (`LONG_FORM`) is retained in `scoresheets` to preserve schema compatibility with future discipline formats.
2. **BJCP Beer Scope (`BJCP_2021`)**: Style linking on a Scoresheet is scoped to `BJCP_2021` beer styles (via a typable searchable dropdown with custom text fallback) because Mead and Cider use distinct judging formats that will be modeled separately later.
3. **In-Place Reference Quick-Peeks**: To keep unsaved evaluation state intact during judging, tapping the style book icon, any section's `(i)` info icon, the scoring-tier `(i)` guide icon, or long-pressing an Off-Flavor chip opens a single-back `ModalBottomSheet` (`skipPartiallyExpanded = true`) with the linked `BeerStyle` stats/section text, BJCP scoring guide, or `OffFlavor` thresholds and origins, rather than navigating away.
